# V17 文案口吻：像一个认真做过功课的人

## 写作目标

读者不需要先懂术语。每段先回答“这和我有什么关系”，再给出处、限制和下一步。语气平静、具体，不装熟，也不替读者做决定。

## 六条规则

1. 先说读者正在做的事，再介绍产品名和术语。
2. 用具体名词和动作：价格看哪里、账号归谁、下一步点哪里。
3. 自动检查只能证明入口、版本、文件或数据状态；用途、风险和建议必须由人阅读来源后写。
4. 不知道就写不知道。读取失败、同页冲突、资料过期都不能用旧数字填空。
5. 不使用“赋能、颠覆、一站式、极致体验、海量资源”等空泛词。
6. 推广关系直接披露，但不把内部追踪码、核验流程写进购买按钮旁边。

## 页面顺序

`用户的问题 → 一句话结论 → 证据/状态 → 风险边界 → 可执行入口`

## 例子

- 不写：“覆盖最全面，打造极致AI体验。”
- 改写：“如果你第一次使用AI，可以先用同一份文件试两款产品，再看哪款更顺手。”
- 不写：“推广入口已自动核验，推广码已保留。”
- 改写：“打开购买页面”。追踪参数由发布门禁检查，不打扰读者。
- 不写：“公开价读取异常”后继续展示旧价。
- 改写：“暂时无法核验；请以购买页当前显示为准。”

## 更新边界

- 每 6 小时自动检查：公开入口、版本、官方文件、SHA-256、价格候选、汇率、榜单快照。
- 发布前自动阻止：追踪码丢失、文件与版本不一致、可信数据过期、构建或测试失败。
- 人工复核：产品用途、适合人群、账号与隐私风险、购买建议。核心人工资料超过 45 天未复核时，不允许发布。
