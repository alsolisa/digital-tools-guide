## 仍然不能夸大的边界

- 这些结果证明本次代码、静态包和实验室环境达到 V16 门禁，不代表网站已获得 Awwwards、Webby、FWA 或 CSSDA 的外部评审或奖项。
- Lighthouse 是单次本地实验室数据，不等于真实访客 28 天 Core Web Vitals；上线后仍需持续观察真实设备和网络。
- Claude 当前公开购买页无法稳定读取统一月价，Grok 同页存在冲突价格；页面按规则隐藏数字并引导用户在购买页确认，这属于正确降级，不是“已核验价格”。
