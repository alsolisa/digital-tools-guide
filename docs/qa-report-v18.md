# V18 严格验收报告

日期：2026-08-14（Asia/Shanghai）

## 结论

当前本地版本已通过发布前能客观证明的内容、数据、工程与响应式门禁，可以进入人工确认发布阶段。这里的“通过”不等于获得 Awwwards、Webby、FWA 或 CSSDA 评审认可，也不能替代上线后的真实用户体验数据。

## 本轮修复

- 五个机场方案增加“本轮能确认”，把入口状态与仍需登录或人工确认的套餐信息分开。
- GamsGo 商品页可以打开但价格结构无法稳定解析时，保留七天内最近可信快照并公开标为历史证据；冲突或没有可信快照的项目继续隐藏数字。
- AI 订阅五张卡片统一使用“打开购买页面”，地址从推广清单读取；删除“推广入口已自动核验”“推广码已保留”等内部文案。
- 原“03 付款前先算价值，再检查账号和售后”整章已删除，自动测试阻止它重新出现。
- 机场页和下载中心提供四个官方文件直链；三份本站备用文件必须同时匹配版本、大小和 SHA-256 才显示。
- 发布门禁增加常见 API 密钥、访问令牌和私钥标记扫描，只报告疑似文件，不输出凭据内容。

## 浏览器视觉验收

- 桌面端 1440×900：首页、机场、AI 订阅、下载、AI、常用应用和模型评测均无横向溢出；每页一个 H1；核心证据图完整显示。
- 手机端 390×844 与 320×780：上述七个入口均无横向溢出；全站菜单、AI 四项二级导航和五个订阅主按钮均达到至少 44px 触控高度。
- 机场页官方发布页、官方文件、本地备份和教程按钮复验后的最小高度为 63px。
- 订阅页五个价格状态说明均存在；禁用推广内文和已删除章节均未出现。

## 严格边界

- 商家公开页当前没有稳定暴露六项产品的专用价格结构，因此不能把“页面能打开”写成“价格已核验”。
- 第三方库存、结算价格、付款方式和售后会变化，用户仍需在打开购买页后确认。
- 是否达到国际奖项级别，只能由外部评审和真实用户结果证明；本报告只证明当前版本通过了本地与发布前门禁。
- 上线后仍需持续观察至少 28 天真实设备、真实网络与 Core Web Vitals 数据。
